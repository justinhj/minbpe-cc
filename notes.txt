merge_pairs method pseudo code

merge_pairs(skipping list, pair left value, pair right value, replacement value)

  iterator = 0
  previous = null
  while iterator.peek |n|
    if previous != null
       previous = iterator.next
    endif
    current = iterator.peek
    if previous == left and current == right
      iterator.replaceAndSkipNext(replacement)
    endif
  end

algorithm
when the current element has no skip it means the next element is not deleted by definition

skipping list data structure looks like the table below.
it consists of an array of numeric elements where the top n bits are used to store skip values to indicate deleted elements
an iterator has the power to step through this with the next function and view the next value with peek
next should increment an internal index by 1 
peek should simply return the next value at index + 1

however we support also a replaceAndSkipNext function
this function sets the value of the element at the current index and deletes the following element.

deleting the first element is not supported.

element index   value    skip 
0               10       0   
1               20       0
2               30       0 
3               40       0
4               50       0
